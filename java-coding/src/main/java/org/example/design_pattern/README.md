Here's a comprehensive list of the **main design patterns**, categorized into three types as per the **Gang of Four (GoF)** classification, along with some **additional architectural and concurrency patterns**:

---

## 🔷 **1. Creational Patterns** (object creation mechanisms)

* **Singleton**
* **Factory Method**
* **Abstract Factory**
* **Builder**
* **Prototype**

---

## 🔶 **2. Structural Patterns** (composition of classes and objects)

* **Adapter**
* **Bridge**
* **Composite**
* **Decorator**
* **Facade**
* **Flyweight**
* **Proxy**

---

## 🔸 **3. Behavioral Patterns** (object interaction and responsibility)

* **Chain of Responsibility**
* **Command**
* **Interpreter**
* **Iterator**
* **Mediator**
* **Memento**
* **Observer**
* **State**
* **Strategy**
* **Template Method**
* **Visitor**

---

## 🏛️ **Architectural Patterns** (high-level software design)

* **Model-View-Controller (MVC)**
* **Model-View-ViewModel (MVVM)**
* **Model-View-Presenter (MVP)**
* **Layered Architecture**
* **Microservices**
* **Event-Driven Architecture**
* **Client-Server**
* **Pipe and Filter**
* **Broker**
* **Service-Oriented Architecture (SOA)**

---

## ⚙️ **Concurrency Patterns** (multi-threaded programming)

* **Thread Pool**
* **Producer-Consumer**
* **Read-Write Lock**
* **Future**
* **Scheduler**
* **Guarded Suspension**
* **Active Object**
* **Double-Checked Locking**
